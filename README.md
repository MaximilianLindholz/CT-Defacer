## 🚀 Defacing CT Scans Using TotalSegmentator

In this repository, we present the code used in our paper on defacing CT scans using the TotalSegmentator. We evaluated whether the face masks generated by the TotalSegmentator are sufficient for removing identifiable facial features from CT scans. Fortunately, they appear to be effective, based on our testing! 😊

The provided code should work well with a variety of CT scans, including whole-body scans or scans where only parts of the head are included, as long as the TotalSegmentator can detect a face. If you encounter any unexpected behavior, please let us know! 😊

## Bulky masks, are good masks (most of the time) :) 
One key finding from our work is that, for effective defacing, it’s crucial that the face masks are not too fine or detailed. Masks that are too sharp or distinct can easily be “refaced” using 3D Slicer or other 3D rendering tools, especially when they contrast strongly with the background. To enhance anonymization, we recommend using masks that are bulkier and blurry, which reduces the risk of re-identification. In the image below, the green mask is generated by the TotalSegmentator, while the red mask is produced by the CTA-DEFACE model.

However, for tasks where maintaining more of the facial anatomy is important, using finer masks may be more appropriate. In such cases, fine masks can be considered, or one might opt for a more flexible ethical framework and patient consent process. 😉

Caution: If newer versions of the TotalSegmentator produce finer face masks, we recommend using the version we tested here (as specified in requirements.txt) to avoid potential issues.
